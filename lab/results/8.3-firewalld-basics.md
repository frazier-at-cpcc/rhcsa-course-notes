### Allowing a service: runtime and permanent

```console label="Terminal"
$ sudo systemctl start httpd; curl -s -o /dev/null -w '%{http_code}\n' http://172.18.8.117/
403
$ sudo firewall-cmd --add-service=http
success
$ sudo firewall-cmd --list-services
cockpit dhcpv6-client http ssh
$ sudo firewall-cmd --list-services --permanent
cockpit dhcpv6-client ssh
$ sudo firewall-cmd --reload; sudo firewall-cmd --list-services
success
cockpit dhcpv6-client ssh
$ sudo firewall-cmd --permanent --add-service=http
success
$ sudo firewall-cmd --reload; sudo firewall-cmd --list-services
success
cockpit dhcpv6-client http ssh
```

### Allowing a port

```console label="Terminal"
$ sudo firewall-cmd --permanent --add-port=8080/tcp
success
$ sudo firewall-cmd --reload; sudo firewall-cmd --list-ports
success
8080/tcp
$ sudo firewall-cmd --query-port=8080/tcp
yes
```
