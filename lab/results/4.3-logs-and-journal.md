### Making it persistent

```console label="Terminal"
$ sudo mkdir -p /etc/systemd/journald.conf.d
$ printf '[Journal]\nStorage=persistent\n' | sudo tee /etc/systemd/journald.conf.d/persistent.conf
[Journal]
Storage=persistent
$ sudo systemctl restart systemd-journald
$ ls -ld /var/log/journal
drwxr-sr-x+ 3 root systemd-journal 46 Oct 21 18:07 /var/log/journal
$ sudo ls /var/log/journal/
e1efc03b2eb54461826a66afe9ac7122
$ sudo journalctl --flush; journalctl --disk-usage
Archived and active journals take up 56M in the file system.
```
