### Access a shell prompt
- The objective: ==access a shell prompt and issue commands with correct syntax==, then ==create and edit text files==
- The ==shell== reads a line, expands it, and runs it
  - RHEL 10 ships `bash` 5.2; every account's shell is listed in `/etc/passwd`
- Ways to reach a prompt
  - A text console on the machine (`Ctrl+Alt+F2` and up, topic 1.4)
  - A terminal window on a GNOME desktop
  - `ssh` from another host (topic 1.4), which is how you reach most exam systems
- The prompt is `[user@host dir]$`, set by `PS1` in `/etc/bashrc`
  - It ends in `$` for a regular user and ==`#` for root==
- Check who and where you are before changing anything

```console label="Terminal"
$ whoami; hostname; echo $SHELL
student
servera.lab.example.com
/bin/bash
```

### Issue commands with correct syntax
- A command line is ==command, options, arguments==, split on spaces
  - `ls -l /etc/services`: command `ls`, option `-l`, argument `/etc/services`
- Options change what the command does
  - Short: one dash, one letter; they combine (`-l -h` is `-lh`)
  - Long: two dashes and a word (`--human-readable`)
  - Some take a value: `-u alice`, `--shell=/bin/bash`
- Arguments are what the command acts on: files, users, packages
- `--` ends the options; everything after it is an argument
  - Needed for a file whose name starts with a dash

```console label="Terminal"
$ ls -l /etc/services
-rw-r--r-- 1 root root 701707 Nov 29  2023 /etc/services
$ ls -lh /etc/services
-rw-r--r-- 1 root root 686K Nov 29  2023 /etc/services
$ touch -notes.txt
touch: invalid option -- 'n'
Try 'touch --help' for more information.
$ touch -- -notes.txt; ls -- -notes.txt
-notes.txt
```

| Between commands | Runs the next one |
|---|---|
| `;` | always |
| `&&` | only if the last succeeded (exit 0) |
| `\|\|` | only if the last failed |

- `mkdir -p reports && cd reports`: no `cd` if `mkdir` fails
- `type` shows what a name is: a ==builtin==, an ==alias==, or a program on disk

```console label="Terminal"
$ ls /nope || echo "no such path"
ls: cannot access '/nope': No such file or directory
no such path
$ type cd grep useradd vi
cd is a shell builtin
grep is aliased to `grep --color=auto'
useradd is /usr/sbin/useradd
vi is /usr/bin/vi
```

### Quoting and expansion
- Before it runs a line, bash expands variables, `$( )`, globs, and braces
- ==Double quotes== keep spaces together and still expand `$`
- ==Single quotes== keep everything literal
- A backslash makes the next single character literal

```console label="Terminal"
$ echo "Home is $HOME"
Home is /home/student
$ echo 'Home is $HOME'
Home is $HOME
$ echo "Host: $(hostname -s)"
Host: servera
```

- ==Globbing==: `*` any string, `?` one character, `[abc]` one from a set
  - Matched against file names in the current directory
  - Quote a pattern meant for `grep` or `find -name` so the shell passes it on untouched
- ==Brace expansion== builds lists: `mkdir -p web/{html,logs,conf}`
- A space splits a name into two arguments unless it is quoted

```console label="Terminal"
$ cd /etc; echo host*; echo "host*"
host.conf hostname hosts
host*
$ cd; mkdir -p web/{html,logs,conf}; echo web/*
web/conf web/html web/logs
$ touch "q3 report.txt"
$ ls q3 report.txt
ls: cannot access 'q3': No such file or directory
ls: cannot access 'report.txt': No such file or directory
$ wc -c "q3 report.txt"
0 q3 report.txt
```

### Tab completion and history
- ==Tab completion== fills in commands, paths, and (with `bash-completion`) options, unit names, and package names
  - One `Tab` completes a unique match; a second `Tab` lists the choices
  - Saves typing and typos in paths such as `/etc/NetworkManager/system-connections`
- Bash keeps ==history== in memory and writes it to `~/.bash_history` when the shell exits
  - `HISTSIZE` is 1000 on RHEL 10

| Keys or command | Does |
|---|---|
| `Up` / `Down` | step through earlier commands |
| `Ctrl+R` then text | search history backward |
| `history` | numbered list |
| `!!` | run the last command again |
| `!42` | run history entry 42 |
| `!sys` | latest command starting `sys` |
| `Ctrl+A` / `Ctrl+E` | start / end of the line |
| `Ctrl+U` / `Ctrl+C` | erase the line / cancel |

- `sudo !!` reruns the last command with sudo
- A `!` expansion prints the command it runs, then its output

```console label="Terminal"
$ history 3
   20  hostname
   21  id -un
   22  history 3
$ !host
hostname
servera.lab.example.com
$ echo $HISTSIZE $HISTFILE
1000 /home/student/.bash_history
```

### Create and edit text files with vim
- `vi` and `vim` are on every RHEL system; the exam expects you to edit config files with one of them
  - `vi` comes from `vim-minimal`; `vim` from `vim-enhanced` (syntax colors, more features)
  - RHEL 10 no longer aliases `vi` to `vim`, as the `type` output above shows
  - No `EDITOR` is set, so `crontab -e` and `visudo` open `vi`
- vim is ==modal==: the same key does different things in each mode
  - It starts in ==normal mode==; `i` to type, `Esc` to return, `:` for commands

:::figure 1.1-vim-modes.svg | Every path goes back through normal mode. :wq and :x save the file; :q! throws the changes away.

| Keys (normal mode) | Does |
|---|---|
| `i` `a` `o` `O` | insert before cursor, after it; new line below, above |
| `I` `A` | insert at line start, line end |
| `x` `dd` `5dd` | delete a character, a line, five lines |
| `yy` `p` `P` | copy (yank) a line; put below, above |
| `cc` `cw` | change the whole line, a word |
| `u` `Ctrl+R` | undo, redo |
| `gg` `G` `:12` | first line, last line, line 12 |
| `/text` `n` `N` | search forward; next, previous match |
| `:%s/old/new/g` | replace in every line |
| `:w` `:wq` `:x` | write; write and quit; same as `:wq` |
| `:q!` | quit and ==discard changes== |

- `vimtutor` is a 30-minute lesson built into `vim-enhanced`; do it before the exam

### Editing with nano
- ==nano== is simpler if you never learned vim (`sudo dnf install nano` if it is missing)
- The two bottom lines list the keys; `^` means `Ctrl`

| Keys | Does |
|---|---|
| `Ctrl+O`, `Enter` | write the file |
| `Ctrl+X` | exit (asks to save changes) |
| `Ctrl+W` | search |
| `Ctrl+K` / `Ctrl+U` | cut the line / paste it |
| `Alt+U` | undo |

- Other ways to create a file: ==touch== (empty), `echo` or a here document with `>` (topic 1.2), `cp` from a template

:::exam
- Nearly every task edits a file under `/etc`. Know enough vim to open a file, change a line, save with `:wq`, and leave with `:q!`; the grader only sees the file.
- Watch for a prompt ending in `#`. A file created as root is owned by root, which breaks a task that says "as user alice".
- Quote values that contain spaces or `$`: a comment, a password, a pattern for `grep` or `find`.
:::
