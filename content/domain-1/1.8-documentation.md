### The exam's open book
- The objective: ==locate, read, and use system documentation== including `man`, `info`, and files in `/usr/share/doc`
- No internet during EX200; the documentation on the system is the only reference you get
  - Learning to find an answer in two minutes is worth more than memorizing options
- Four sources, quickest first
  - `cmd --help`: a one-screen option summary
  - `man cmd`: the full reference page
  - `info cmd`: longer GNU manuals split into linked nodes
  - `/usr/share/doc/<package>/`: READMEs, FAQs, and example files
- Shell builtins (`cd`, `export`, `read`) have no page of their own
  - `type cd` tells you it is a builtin; `help cd` explains it

```console label="Terminal"
$ tar --help | grep -- "--bzip2"
  -j, --bzip2                filter the archive through bzip2
$ type cd
cd is a shell builtin
$ help cd | head -2
cd: cd [-L|[-P [-e]] [-@]] [dir]
    Change the shell working directory.
```

### man pages and sections
- Pages are grouped into numbered ==sections==; the same name can exist in several
  - `man passwd` opens the first match in section order: the command in section 1
  - `man 5 passwd` opens the file format of `/etc/passwd`
- ==`man -f name`== (same as `whatis`) lists every section that has the name
- `man -w` prints the file a page lives in; `man -aw` prints all of them

```console label="Terminal"
$ man -f passwd
passwd (1)           - change user password
passwd (5)           - password file
$ man -w 5 passwd
/usr/share/man/man5/passwd.5.gz
```

| Section | Contains | Example |
|---|---|---|
| 1 | user commands | `ls(1)`, `tar(1)` |
| 2, 3 | system and library calls | `open(2)` |
| 4 | device files | `null(4)` |
| 5 | file formats and config files | `passwd(5)`, `crontab(5)` |
| 7 | overviews, conventions | `nmcli-examples(7)` |
| 8 | administration commands | `useradd(8)`, `mandb(8)` |

- Page layout is always the same: NAME, SYNOPSIS, DESCRIPTION, OPTIONS, then FILES, EXAMPLES, and SEE ALSO near the end
- Reading a SYNOPSIS
  - `[ ]` optional, `...` may repeat, `a|b` one or the other
  - Bold text is typed as shown; underlined text is a value you supply
- Jump straight to the end with `G` to find EXAMPLES and SEE ALSO

### Searching with man -k
- ==`man -k keyword`== (same as ==`apropos`==) searches every page's NAME line
  - Use it when you know the topic but not the command
  - The pattern is a regular expression: `man -k '^passwd'` keeps only names that start with passwd
  - `apropos -s 8 passwd` limits the search to one section
- ==nmcli-examples(7)== is the page to remember for networking tasks

```console label="Terminal"
$ man -k nmcli
nm-settings (5)      - Description of setting...
nm-settings-nmcli (5) - Description of settin...
nmcli (1)            - command-line tool for ...
nmcli-examples (7)   - usage examples of nmcli
```

- The search reads an index database built from the pages
  - "nothing appropriate" for a page that exists means the database is stale
  - ==`sudo mandb`== rebuilds it
- RHEL 10 has no cron job for this
  - An RPM file trigger in `man-db` starts `man-db-cache-update.service` after dnf installs pages
  - Pages installed by other means (a container, a copied tree) wait until you run `mandb`

```console label="Terminal"
$ man -k crontab
crontab: nothing appropriate.
$ sudo mandb
3216 manual pages were added.
$ man -k crontab
anacrontab (5)       - configuration file for...
crontab (1)          - maintains crontab file...
crontab (5)          - files used to schedule...
```

### Moving around in man
- man shows pages through the `less` pager

| Key | In man (less) |
|---|---|
| `Space` / `b` | next page / back a page |
| `/text` | search forward |
| `n` / `N` | next / previous match |
| `g` / `G` | top / end of the page |
| `h` | help with the keys |
| `q` | quit |

### info documents
- GNU tools keep their full manuals in ==info== format under `/usr/share/info`
  - `tar`, `coreutils`, `bash`, `gzip`
  - More tutorial than a man page; split into ==nodes== linked by menus
- `info tar` opens the top node; `info coreutils 'ls invocation'` opens one node directly
- Each node's header names its neighbors

```console label="Terminal"
$ info -w tar
/usr/share/info/tar.info.gz
$ info coreutils "ls invocation" | head -1
File: coreutils.info,  Node: ls invocation,  Next: dir invocation,  Up: Directory listing
```

| Key | In info |
|---|---|
| `Space` / `Backspace` | scroll forward / back |
| `n` / `p` / `u` | next / previous / up node |
| `Tab`, then `Enter` | move to a link, follow it |
| `l` | go back to the last node visited |
| `s` or `/` | search |
| `q` | quit |

### /usr/share/doc
- Packages drop extra documentation in ==`/usr/share/doc/<package>/`==
  - README, FAQ, NEWS, and example configuration files
  - License texts live separately in `/usr/share/licenses`
- `rpm -qd package` lists every document a package installed, including its man pages
  - Tells you which man sections to look in

```console label="Terminal"
$ rpm -qd chrony
/usr/share/doc/chrony/FAQ
/usr/share/doc/chrony/NEWS
/usr/share/doc/chrony/README
/usr/share/doc/chrony/chrony.keys.example
/usr/share/man/man1/chronyc.1.gz
/usr/share/man/man5/chrony.conf.5.gz
/usr/share/man/man8/chronyd.8.gz
```

- Example files are made to be copied and edited
  - Copy them out first; never edit the original under `/usr/share/doc`

:::exam
- No task says "use man," but every task can be unlocked by it. Under time pressure, `man -k` plus `/EXAMPLE` inside the page is the fastest route to forgotten syntax.
- Know when you need section 5: the format of a configuration file (`crontab(5)`, `passwd(5)`, `fstab(5)`) is never on the section 1 or 8 page.
- If `man -k` says "nothing appropriate" for a command you can run, rebuild the index with `mandb` and search again.
:::

:::try
Without using the internet, find the man page that documents the format of /etc/fstab, list every section that has a page called crontab, and locate the example key file that the chrony package ships. Write down the command you used for each.
:::
