### Flatpak on RHEL 10
- ==Flatpak== installs applications in a format that sits beside RPM
  - Each ==app== runs on a shared ==runtime==: a base set of libraries
  - The app runs in a sandbox built with `bubblewrap`
  - `dnf` never sees Flatpak apps; `flatpak` never sees RPMs
- RHEL 10 ships `flatpak` 1.16 in AppStream
  - Desktop installs get Firefox and Thunderbird as Flatpaks by default
  - A minimal server may need `sudo dnf install flatpak` first
- Everything is named by a reverse-DNS ID: `com.github.ilai_deutel.kibi`

| Term | Meaning |
|---|---|
| Remote | A Flatpak repository, like a dnf repo |
| App | The program, e.g. `com.github.ilai_deutel.kibi` |
| Runtime | Shared libraries apps run on |
| Installation | Where refs land: system or user |

:::figure wide 2.2-flatpak.svg | flatpak install copies an app and the runtime it needs from a remote into the system or a user installation. flatpak run starts the app on top of that runtime inside a sandbox.

### Configure access to Flatpak repositories
- A ==remote== is a Flatpak repository
  - Add one from a `.flatpakrepo` file: it carries the URL, title, and GPG key
  - ==flatpak remote-add== `--if-not-exists` makes a rerun harmless
- System remotes live in `/var/lib/flatpak/repo/config`
  - A plain file read on every run, so the remote survives a reboot

```console label="Terminal"
OUT_REMOTEADD
```

- Look before you install
  - `flatpak remote-ls flathub --app`: every app on a remote
  - `flatpak search kibi`: match names and descriptions
  - `flatpak remote-info flathub ID`: version, size, runtime

```console label="Terminal"
OUT_BROWSE
```

- `flatpak remote-modify --disable rhel` hides a remote; `--enable` brings it back
- `flatpak remote-delete rhel` removes it

### Flathub and the Red Hat registry
:::wide
| | Flathub | Red Hat Flatpak registry |
|---|---|---|
| Remote file | `https://dl.flathub.org/repo/flathub.flatpakrepo` | `https://flatpaks.redhat.io/rhel.flatpakrepo` |
| Usual name | `flathub` | `rhel` |
| Content | Thousands of community and vendor apps | Apps built from RHEL packages: Firefox, Thunderbird, runtimes |
| Access | Anyone | Listing is open; installing needs a subscribed system |
| Support | Community | Red Hat |
:::

- ==Flathub== is the large public catalog most guides use
- The ==Red Hat Flatpak registry== serves apps as OCI images (`oci+https://` URL)
  - A registered RHEL system authenticates with its subscription
  - An unregistered system can list it but not install from it

```console label="Terminal"
OUT_RHEL
```

### Install, run, and remove Flatpak software packages
- ==flatpak install== REMOTE ID pulls the app and the runtime it needs
  - `-y` and `--noninteractive` skip the prompts
  - `--no-related` skips optional extensions (translations, GPU drivers)
- `flatpak list` shows apps and runtimes; `--app` hides runtimes
- ==flatpak run== ID starts the app in its sandbox
  - Desktop apps also appear in the GNOME application menu
- `flatpak uninstall ID` removes the app but leaves its runtime
  - `flatpak uninstall --unused` removes runtimes nothing needs
- `flatpak update` updates every installed app and runtime

```console label="Terminal"
OUT_INSTALL
```

### System and user installations
- The ==system installation== is the default: `--system`
  - Lands in `/var/lib/flatpak`; every user can run the app
  - Changing it needs `sudo` (or a polkit prompt on a desktop)
- A ==user installation== belongs to one account: `--user`
  - Lands in `~/.local/share/flatpak`; no root needed
  - Needs its own remote: `flatpak remote-add --user`
- `flatpak list` and `flatpak remotes` show both, with an installation column

```console label="Terminal"
OUT_USER
```

:::exam
- "Install the Flatpak app ID from the repository at URL so that all users can run it" means a system remote and a system install, done with `sudo`. A `--user` install passes your own check and fails the grader's check as another user.
- Remotes and installed apps are plain files under `/var/lib/flatpak`, so they persist across reboots with nothing to enable. Verify with `flatpak remotes` and `flatpak list --app`.
- Know the difference between removing an app (`flatpak uninstall`) and removing access to a repository (`flatpak remote-delete`).
:::
